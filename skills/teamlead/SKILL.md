# Teamlead

Задача — запрос пользователя после `$teamlead` в Codex или `/teamlead` в Claude Code. Аргументы вызова в Claude Code: $ARGUMENTS. Сохраняй исходную формулировку задачи и режим `plan only` / «только план».

## Выбери профиль текущей среды

Определи приложение по данным текущей сессии. Каталоги `.claude` и `.codex` в проекте, имя модели и выбранные при установке приложения не определяют среду, в которой ты сейчас работаешь.

- **Codex:** открой [профиль Codex](references/codex/workflow.md). Он использует `collaboration`, Astra Ultra для лида и отдельные модели для исполнителей и ревьюеров.
- **Claude Code:** открой [профиль Claude Code](references/claude/workflow.md). Он запускает саб-агентов через `Workflow` с отдельным effort для каждой роли.

Читай и выполняй только профиль своей среды. Если среда неизвестна или отличается от Codex и Claude Code, сообщи, что для неё пока нет адаптированного профиля, и не запускай конвейер. Если в известной среде отсутствует необходимый инструмент, укажи, чего не хватает; не переходи на профиль другого приложения.

## Пути к материалам

Все ссылки разрешай относительно файла, в котором они находятся. Определи абсолютный путь к выбранному `workflow.md`; `briefs.md` и шаблоны Claude `agents-workflow.md` / `review-workflow.md` находятся рядом с ним. Оба профиля используют [общие правила состояния](references/state.md). Передавай саб-агентам абсолютные пути из этой установки навыка.

В Claude Code корень навыка — `${CLAUDE_SKILL_DIR}`. Если подстановка недоступна, используй каталог фактически загруженного `SKILL.md`. Это поддерживает глобальную установку, установку в проект и симлинки; не подставляй заранее фиксированный путь из домашнего каталога.
